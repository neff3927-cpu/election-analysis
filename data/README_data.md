# 데이터 안내

이 프로젝트는 발표 중 업로드 위젯을 요구하지 않습니다. 전국 단위 요약 데이터는 app.py 안에 포함되어 즉시 차트로 표시됩니다.

다만 제20~22대 전체 선거구별 인구 원자료가 확보되지 않아 2번의 인구별 색상/Top 10, 3번의 인접 평균 색상, 4번의 실제 Box Plot은 임의로 만들지 않았습니다. 지도는 제22대 선거구 경계 GeoJSON을 인터넷에서 가져와 경계 참고용으로 표시합니다.

경계 원본: https://github.com/OhmyNews/2024_22_elec_map
전국 선거인수 참고: 중앙선거관리위원회 총람 및 행정안전부 공개자료
