# 데이터 파일 안내

## 기본 포함 자료
- `election_history_summary.csv`: 제20·21·22대 총선의 최대·최소·평균 인구 요약. 총선별 기준일과 출처가 다를 수 있으므로 표와 설명에 함께 표시합니다.
- `election_voters_national.csv`: 제20·21·22대 총선 전국 주민등록인구 및 선거인수 합계. 전국 수준 관계를 보여주는 참고 자료이며 선거구별 분석으로 해석하면 안 됩니다.

## 추가 원자료 템플릿
- `constituency_population_template.csv`: 제22대 254개 선거구의 주민등록인구를 넣습니다. `SIDO_SGG`는 지도 GeoJSON의 `properties.SIDO_SGG`와 정확히 일치해야 합니다.
- `historical_constituencies_template.csv`: 각 총선별 선거구 전체 인구 원자료를 행 단위로 입력합니다. 이 파일이 있어야 4번 분포 차트를 실제로 그릴 수 있습니다.
- `election_voters_district_template.csv`: 선거구별 주민등록인구·선거인수 원자료를 입력하면 6번이 전국 합계 대신 선거구별 산점도로 전환됩니다.

## 분석 정의와 한계
- 표의 등가성 지수 = 해당 총선의 선거구 평균 주민등록인구 ÷ 해당 선거구 주민등록인구.
- 인접 비교: 선거구 경계가 실제 공유 경계를 갖는 경우를 인접으로 보고, 인접 선거구 평균 인구와 비교합니다.
- 5번 상대지수 = 첫 관측 총선의 최대/최소 인구비율 ÷ 해당 총선의 최대/최소 인구비율 × 100. 첫 관측 총선을 100으로 둔 프로젝트 자체의 탐색용 상대지수이며 공식 지표나 법적 적정성 판정이 아닙니다.
- 6번 기본 데이터는 전국 합계입니다. 선거구별 인구-선거인수 관계를 분석하려면 선거구별 데이터 파일이 필요합니다.
- 실제 투표자수는 선거인수와 다르며, 주민등록인구에는 미성년자가 포함됩니다.
