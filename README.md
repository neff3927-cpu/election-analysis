# 국회의원 지역구 인구와 표의 등가성 분석

## 배포
저장소 최상위에 `app.py`, `requirements.txt`, `data/` 폴더를 그대로 업로드하세요. Streamlit Cloud의 Main file path는 `app.py`로 설정합니다.

이 버전은 CSV 업로드 위젯을 제거했고 지도 컴포넌트에 고유 key를 부여했습니다. CARTO 대신 OpenStreetMap 타일을 사용합니다.

## 데이터 한계
전국 요약 차트는 바로 표시됩니다. 단, 선거구별 원자료가 아직 확보되지 않은 2·3·4번의 실제 색상·Top 10·분포는 임의 생성하지 않고 데이터 미확보 상태를 화면에 표시합니다. 지도 경계는 인터넷 연결이 필요합니다.
