# 국회의원 지역구 인구와 표의 등가성 분석 대시보드

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub 업로드
저장소 최상위에 `app.py`, `requirements.txt`, `data/` 폴더가 오도록 업로드하세요.

## 첫 화면과 6개 옵션
1. 역대 총선별 선거구 최대·최소·평균 인구 변화: 차트만 표시
2. 선거구별 인구수 및 표의 등가성 지수: 지도 + Top 10 차트
3. 인접 선거구와의 인구 차이: 지도만 표시. 인접 선거구 평균보다 많으면 빨강, 적으면 파랑, 같으면 회색
4. 총선별 표의 등가성 지수 분포: 선거구별 원자료를 선택한 총선 기준으로 히스토그램 표시
5. 총선 시기별 표의 등가성 변화 분석: 최대·최소 인구비율의 변화와 프로젝트 자체 상대지수 표시
6. 주민등록인구와 유권자수(선거인수)의 관계 분석: 선거구별 자료가 있으면 산점도, 없으면 전국 합계 산점도

## 데이터 주의
제22대 선거구 GeoJSON은 공개 저장소에서 실행 시 불러옵니다. 선거구별 인구·선거인수의 전체 원자료는 별도 공식 CSV가 필요합니다. 데이터가 없는 분석을 임의의 값으로 채우지 않으며, 업로드 템플릿을 `data/`에 제공합니다.

5번의 상대지수는 첫 관측 총선 대비 최대·최소 인구비율의 상대 변화로 정의한 프로젝트 자체 참고 지표입니다. 공식 민주주의 지수나 법적 위반 판단 기준이 아닙니다.

자세한 데이터 구조는 `data/README_data.md`를 확인하세요.
