신규 대시보드 구현
- 첫 화면을 6개 분석 옵션 선택 중심으로 재구성
- 1,4,5,6은 차트 전용 / 2는 지도+Top10 / 3은 지도 전용
- 선택 옵션에 따라 관련 입력 위젯만 표시
- 제22대 254개 선거구 경계 GeoJSON을 실행 시 자동 로드하도록 구현
- 선거구 경계의 공유 경계를 이용해 인접 선거구 자동 계산
- 인접 평균 대비 인구 차이 빨강/파랑/회색 분류
- 전국 수준 제20·21·22대 주민등록인구-선거인수 데이터 포함
- 5번 프로젝트 자체 상대지수 계산식과 한계 표시
- 실제 원자료가 없는 선거구 인구/역대 분포는 임의 생성하지 않고 템플릿 제공
